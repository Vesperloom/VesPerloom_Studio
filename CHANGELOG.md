# Changelog

## 0.3.0 · Motion & language edition

- Three connected React desks: streaming chat → editable image prompt → scene-linked video shot. The native image fingerprint and offline Seed Lab remain compatible.
- Strata Motion camera trajectories and animated tidal surfaces; 2–4 s native MP4 up to wide 720p/24 fps, WebM review fallback, posters, frame strips and verifiable motion recipes.
- Opt-in GGUF CPU runtime, small and 7B Qwen inventories, headless/interactive chat CLI and optional operator-configured compatible streaming endpoint.
- Opt-in Wan 2.1 text-to-video tensor worker with a real, offline tiny-pipeline test. Full third-party checkpoints except the 0.5B chat model were not run in the CPU release environment.
- Named workspace keys, scoped media and job visibility, quotas, bounded generation, private project shelves, cancellation and protected media playback.

## 0.2.0 · Seed Lab & community edition

- Added the project Telegram channel to all four README editions, the studio sidebar, Seed Lab and GitHub issue contact links.
- New self-contained browser edition of the native engine. Includes the trained weights, an offline worker, and the same sampler and RGBA renderer as Node.
- Privacy-limited `VL1` remix codes, a shared Monday UTC seed, and opt-in 1200×630 postcard export. The original unbranded PNG and replay capsule formats are unchanged.
- Opt-in GitHub Pages deployment and configurable repository/star links. Public remix links never use the private studio origin.
- The studio release is 0.2.0; the pixel engine remains 0.1.0 to preserve replay compatibility.

## 0.1.0 · Initial source release

- Bundled Strata-1 scene-code diffusion checkpoint, NumPy trainer and CPU renderer.
- React image studio, scene studies, gallery, registry and English field guide.
- Seed-drift branching, named parents and model-bound replay capsules with decoded-pixel verification.
- Single-worker Node service with bounded jobs, deadlines, cancellation, atomic output and restart-safe gallery records.
- Pinned SD 1.5, SDXL Base, SDXL Turbo and FLUX.1 Schnell profiles; staged pull, offline import and content verification.
- Four README editions, native Docker deployment, example systemd service and optional offline tensor tests.
